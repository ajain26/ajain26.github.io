# ajain26.github.io

Developer website for Anshul Jain's apps. It serves `app-ads.txt` at the site root, which AdMob reads to
authorize ads for every app whose store listing names `https://ajain26.github.io/` as its website.
Privacy policies live in the separate `app-policies` repo, served at `https://ajain26.github.io/app-policies/`.
